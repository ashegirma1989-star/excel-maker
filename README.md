# Finance Manager

A simple browser-based income and expense tracker for Ashenafi Girma to review financial activity across four companies.

## Features

- Record income and expenses in Ethiopian birr (ETB)
- Track transactions for each company and rename the four company placeholders
- Filter the dashboard by company and reporting month
- Review income, expenses, and net cash flow totals
- Delete individual transactions and export filtered records to CSV
- Save data in browser local storage; entries are not sent to a server

## Run

Open `index.html` in a modern browser. No build step or account is required. Data is stored only in that browser on that device, so export CSV backups regularly. Clearing browser site data or changing devices can remove access to the saved entries.

This lightweight tracker is not a full accounting system and does not replace professional accounting records or advice.
